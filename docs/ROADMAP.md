# Roadmap — Stay Forward-Looking

Prioritize what customers will still pay for as AI-assisted offense becomes table stakes.

## Now (foundation — this repo)

- [x] Product vision & service catalog  
- [x] Dual-agent architecture (Claude red / Codex blue)  
- [x] Stub orchestrator + authorized lab demo  
- [ ] Internal Tier 0 demos to leadership  
- [ ] One design-partner Purple Sprint  

## Next (pilot-ready)

- Live Claude provider adapter (structured findings JSON)  
- Live Codex provider adapter (diff + test generation)  
- Engagement workspace: scope file, audit log, artifact portal  
- Playbook v1: web app misconfig, identity/cloud IAM shape, secrets hygiene  
- Customer-facing report template (exec + technical)

## Later (retainer differentiators)

- CI/CD gate: PRs carry adversarial hypotheses for touched surfaces  
- AI-stack pack: agent/MCP/RAG resilience checks (customer-owned endpoints)  
- Detection export → customer SIEM  
- Re-test pass-rate scorecards (prove Codex closure quality)  
- Vertical playbooks (fintech, health, B2B SaaS)

## Bet-the-company themes (watch & shape)

| Theme | Why demand grows | OSC response |
|-------|------------------|--------------|
| Agentic AI in production | Tool misuse = new breach class | Tier 3 AI add-on + continuous |
| AI-augmented attackers | Human red team alone can’t match cadence | Dual-agent continuous retainer |
| Board / regulator AI risk | Evidence > narratives | Tier 4 assurance pack |
| Mean-time-to-remediate | CISOs judged on closure | Codex-in-the-loop fixes |
| Purple > red or blue alone | Orgs want one accountable outcome owner | Attack → Defend as the SKU |

## Explicitly deferred

- Autonomous production exploitation  
- Malware / exploit payload productization  
- Commodity CVE scanning as the core (partner or integrate, don’t become it)

## Decision checkpoints

After each design-partner sprint, ask:

1. Did Claude findings survive authorized validation ≥ target rate?  
2. Did Codex remediations merge with low rework?  
3. Would the customer pay monthly to keep the loop running?  

If (3) is weak, fix packaging before adding model features.
